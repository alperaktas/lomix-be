1. Genel Bilgiler

Base URL

OrtamURL
Productionhttps://lomix-be-i2rg.vercel.app
Developmenthttp://localhost:3000

Kimlik Doğrulama

Korumalı tüm endpoint'ler Authorization header'ı gerektirir:

Authorization: Bearer <JWT_TOKEN>

Token, login / register / social login endpoint'lerinden döner. Süresi dolunca tekrar login yapılması gerekir.

Standart Yanıt Formatı

Yeni endpoint'ler (ApiResponseHelper):

{
  "success": true,
  "message": "İşlem başarılı.",
  "data": { ... }
}

Eski endpoint'ler (create, join, leave) — aynı yapı ama alan adı farklı:

{
  "status": true,
  "message": "İşlem başarılı.",
  "data": { ... }
}
ℹ️ Başarı kontrolü için hem success hem status alanını kontrol edin veya sadece HTTP durum koduna göre işlem yapın.

HTTP Durum Kodları

KodAnlam
200Başarılı
201Kayıt oluşturuldu
400Hatalı istek / eksik parametre
401Token yok veya geçersiz
403Yetkisiz (token var ama izin yok)
404Kayıt bulunamadı
409Çakışma (zaten mevcut)
500Sunucu hatası

9. Agora Signaling (RTM) Entegrasyonu

Nasıl Çalışır?

Backend, aksiyon endpoint'lerinden rtm_event alanı döner. Flutter client bu objeyi alıp Agora Signaling kanalına yayınlar. Diğer tüm katılımcılar bu mesajı dinleyerek UI'ı günceller.

ℹ️ Admin paneli aksiyonları (kapat, kick, mute vb.) Agora RTM REST API üzerinden event'i doğrudan kanala push eder — Flutter'ın herhangi bir şey yapmasına gerek kalmaz, dinleyici otomatik tetiklenir.
// Aksiyon endpoint'i çağrıldıktan sonra:
final res = await api.post('/api/mobile/room/mic/take', { 'roomId': roomId, 'slotIndex': 2 });
if (res['success'] == true && res['data']['rtm_event'] != null) {
  await rtmChannel.sendMessage(
    AgoraRtmMessage.fromText(jsonEncode(res['data']['rtm_event']))
  );
}

// Diğer kullanıcılarda dinleyici:
rtmChannel.onMessageReceived = (AgoraRtmMessage msg, String memberId) {
  final event = jsonDecode(msg.text);
  switch (event['type']) {
    case 'MIC_TAKEN':
      updateMicSlot(event['slotIndex'], event['userId'], event['username']);
      break;
    case 'KICKED':
      if (event['targetUserId'] == myUserId) leaveRoom();
      break;
    // ...
  }
};

Token Akışı

Join endpoint'i sadece Agora RTC token döndürür. Odaya girdikten sonra iki ek token alınmalıdır:

  • POST /api/mobile/room/signalling-token — Oda event'leri için (USER_JOINED, KICKED vb.). roomId gerektirir, channel_name döner.
  • POST /api/mobile/room/chat-token — Agora Chat mesajlaşma için. Body gerekmez, uygulama açılışında bir kez alınabilir.

MIC_LOCKED/room/mic/lockslotIndex, isLocked, freedUserId
